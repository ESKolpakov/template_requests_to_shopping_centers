# Как подготовить шаблон письма

Приложение **не содержит** готового бланка письма — ни реального бланка
ГБУ «МКМЦН», ни какого-либо другого документа-шаблона. Это сознательное
решение: бланк и образцы писем содержат официальные реквизиты и
персональные данные, и не публикуются в открытом репозитории (см.
README.md, раздел «Приватность»). Вместо этого шаблон загружается
пользователем через вкладку **«Шаблоны»** — один раз, а дальше
переиспользуется при каждой генерации.

Хорошая новость: подготовить шаблон нужно **один раз**, и это можно
сделать прямо в Word поверх уже существующего у вас бланка/образца
письма — правкой обычного текста, без макросов и работы с XML.

## 1. Возьмите за основу один из ваших реальных писем

Откройте в Word любое ваше готовое письмо «Об оказании содействия»
(со всей вёрsткой, шрифтами, шапкой ГБУ «МКМЦН», футером и таблицей) —
и сохраните его копию как файл шаблона. Дальше в этой копии переменные
части текста заменяются плейсхолдерами вида `{{ИМЯ_ПЛЕЙСХОЛДЕРА}}` —
как обычный текст, руками, прямо в Word.

Важно: плейсхолдер — это просто текст. Не нужно менять шрифт, стиль или
структуру документа — заменяете, например, «Европолис» на `{{TC_NAME}}`
прямо в предложении, оставляя всё форматирование как было.

## 2. Простые текстовые плейсхолдеры

Расставьте по тексту письма (в адресном блоке, в теле, в подписи) там,
где раньше стояли переменные данные конкретного письма:

| Плейсхолдер | Что подставится |
|---|---|
| `{{RECIPIENT_BLOCK}}` | Весь адресный блок одним куском (несколько строк: должность/УК/ФИО/адрес, либо «Администрация торгового центра» + адрес) |
| `{{RECIPIENT_BLOCK_MAIN}}` | Только должность/УК/ФИО (или «Администрация торгового центра») — без юридического адреса |
| `{{RECIPIENT_BLOCK_ADDRESS}}` | Только юридический адрес получателя (или адрес ТЦ для обезличенного варианта) |
| `{{GREETING}}` | «Уважаемый Имя Отчество!» / «Уважаемая Имя Отчество!» / пусто |
| `{{TC_NAME}}` | Название торгового центра |
| `{{TC_ADDRESS}}` | Адрес торгового центра |
| `{{DEADLINE_DATE}}` | Рассчитанная дата срока (ДД.ММ.ГГГГ) |
| `{{EXECUTOR_NAME}}` | Исполнитель (из настроек) |
| `{{EXECUTOR_PHONE}}` | Телефон исполнителя (из настроек) |
| `{{SIGNATORY_NAME}}` | Подписант (из настроек) |

`{{RECIPIENT_BLOCK}}` и его разрезанная на две части версия
(`{{RECIPIENT_BLOCK_MAIN}}` + `{{RECIPIENT_BLOCK_ADDRESS}}`) содержат ОДНУ
и ТУ ЖЕ информацию — просто под разную вёрстку шаблона:

- Если в вашем бланке весь адресный блок — один абзац/одна ячейка с
  одним отступом, используйте один `{{RECIPIENT_BLOCK}}` — каждая строка
  подставится через перенос строки внутри того же абзаца (без разрыва
  абзаца), форматирование (шрифт, отступ) наследуется от абзаца, где
  стоит плейсхолдер.
- Если в вашем бланке должность/УК/ФИО и юридический адрес набраны
  РАЗНЫМИ абзацами с разным отступом «лесенкой» (как в примерах писем
  ГБУ «МКМЦН» — адрес чуть глубже проваливается вправо, чем должность/
  ФИО), поставьте `{{RECIPIENT_BLOCK_MAIN}}` в одном абзаце, а
  `{{RECIPIENT_BLOCK_ADDRESS}}` — в следующем, с нужным (более глубоким)
  отступом. Оба плейсхолдера можно использовать одновременно — не
  использованный шаблоном плейсхолдер просто останется невостребованным.

Как и в примерах писем, удобно располагать эти плейсхолдеры внутри
невидимой (без границ) таблицы-«подложки» для адресного блока — но это
не обязательное требование. Единственное, чего стоит избегать при
редактировании шаблона, — выравнивания пробелами (как это довольно долго
делалось вручную): для отступов используйте абзацный отступ Word
(«Главная» → «Абзац» → «Отступ слева», либо линейку) — тогда при
автозаполнении текст разной длины (разные ФИО/названия компаний) не
съедет вправо/влево непредсказуемо, как бывает с пробелами.

### Словоформы по числу хозяйствующих субъектов (ед./мн. число)

Если в письме один хозяйствующий субъект — используются одни формы слов,
если несколько — другие (см. ТЗ, п.4.2). Приложение подставляет нужную
форму автоматически по числу строк итоговой таблицы. Плейсхолдеры:

| Плейсхолдер | Ед. число | Мн. число |
|---|---|---|
| `{{SUBJECT_WORD_FORM}}` | хозяйствующем субъекте | хозяйствующих субъектах |
| `{{VERB_OSUSHESTVLYAL}}` | осуществлял | осуществляли |
| `{{OBJECT_WORD}}` | объекта | объектов |
| `{{TRADE_OBJECT_PHRASE}}` | торгового объекта | торговых объектов |
| `{{SUBJECT_NOM}}` | хозяйствующий субъект | хозяйствующие субъекты |
| `{{SUBJECT_PREP}}` | хозяйствующем субъекте | хозяйствующих субъектах |
| `{{UKAZANNYY}}` | указанный | указанные |
| `{{OSUSHESTVLYAVSHIY}}` | осуществлявшем | осуществлявших |
| `{{SUBJECT_CLAUSE}}` | осуществлял хозяйствующий субъект, указанный | осуществляли хозяйствующие субъекты, указанные |
| `{{SUBJECT_PREP_CLAUSE}}` | хозяйствующем субъекте, осуществлявшем | хозяйствующих субъектах, осуществлявших |

Используйте либо готовые «фразы целиком» (`{{SUBJECT_CLAUSE}}`,
`{{SUBJECT_PREP_CLAUSE}}`), либо собирайте нужное предложение из
отдельных слов — как удобнее лично вам при редактировании шаблона.

## 3. Таблица объектов торговли

В шаблоне должна быть готовая таблица (с заголовком — как в ваших
письмах) и **ровно одна строка-образец** сразу под заголовком, в ячейках
которой стоят плейсхолдеры:

```
{{ROW.NUM}} | {{ROW.NAME}} | {{ROW.SUBJECT}} | {{ROW.INN}} | {{ROW.ADDRESS}} |
{{ROW.FLOOR}} | {{ROW.ROOM}} | {{ROW.DATE}} | {{ROW.ID}} | (пусто)
```

Порядок столбцов — как в образцах: № п/п, Наименование объекта,
Хозяйствующий субъект, ИНН, Адрес, Этаж, Помещение, Дата сбора
информации, ID, Торговая деятельность подтверждается/не подтверждается
(10-й столбец плейсхолдера не содержит — он всегда остаётся пустым, для
рукописной отметки).

При генерации письма эта строка клонируется столько раз, сколько строк
нужно в конкретном письме, значения подставляются, а если несколько
строк относятся к одному и тому же объекту (общие Наименование/Адрес/
Этаж/Помещение/Дата/ID, разные Хозяйствующий субъект/ИНН) — эти столбцы
автоматически объединяются по вертикали (rowspan), как в образцах.
Исходная строка-образец из итогового документа удаляется.

## 4. Проверка шаблона

После загрузки шаблона на вкладке «Шаблоны» нажмите «Проверить структуру
шаблона» — приложение подсветит отсутствующие обязательные плейсхолдеры
и подтвердит, что строка-образец таблицы найдена.

## 5. Визуальная сверка после генерации

Сгенерируйте пробное письмо и откройте его в Word (или сконвертируйте в
PDF через LibreOffice: `soffice --headless --convert-to pdf файл.docx`)
— сверьте вёрстку с исходным бланком. Поскольку заполнение идёт прямо в
существующих текстовых узлах документа, а не пересборкой с нуля, шрифты,
отступы, границы таблиц и футер остаются такими же, как в загруженном
шаблоне.
